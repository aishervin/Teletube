# پنل استریم پلی‌لیست یوتیوب → تلگرام (روی Railway)

## این پروژه چیه؟
یک سرویس Node.js که:
- یک پنل وب ساده داره (`/`) برای وارد کردن لینک پلی‌لیست یوتیوب و لینک RTMP کانال تلگرام
- با دکمه "شروع استریم"، یک پروسه پس‌زمینه (`worker.js`) اجرا میشه که ویدیوهای پلی‌لیست رو یکی‌یکی با `yt-dlp` می‌گیره و مستقیم (بدون ذخیره روی دیسک) با `ffmpeg` به RTMP تلگرام استریم می‌کنه
- وقتی پلی‌لیست تموم بشه، از اول لوپ می‌زنه
- برخلاف GitHub Actions، چون روی Railway یک پروسه دائمی داری، محدودیت ۶ ساعته وجود نداره

## مراحل دیپلوی

### ۱) این فولدر رو در یک ریپازیتوری گیت‌هاب جدید push کن
```bash
cd streamer
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### ۲) در Railway
اگر از پنل Railway استفاده می‌کنی:
1. New Project → Deploy from GitHub repo → همین ریپو رو انتخاب کن
2. Railway به‌خاطر وجود `Dockerfile` خودش تشخیص میده و build می‌کنه
3. بعد از دیپلوی، در تب Settings سرویس، روی Networking → Generate Domain بزن تا یک URL عمومی برای پنل بگیری

یا به من بگو اسم ریپو (`owner/repo`) رو بعد از push، تا خودم از طریق ابزار Railway بهش وصلش کنم و دامنه‌شو بسازم.

### ۳) گرفتن لینک RTMP کانال تلگرام
در کانال تلگرامت: تنظیمات کانال → Start Voice Chat / Live Stream → Start Streaming with... → یک RTMP URL و Stream Key بهت میده. این‌ها رو به‌صورت یک لینک کامل RTMP وارد پنل کن (یا اگر جدا داد، به فرمت `rtmp://SERVER/STREAM_KEY` باهم بچسبونشون).

### ۴) استفاده از پنل
بعد از باز کردن URL سرویس:
1. لینک پلی‌لیست رو بذار
2. لینک RTMP رو بذار
3. (اختیاری ولی پیشنهاد میشه) کوکی مرورگر لاگین‌شده به یوتیوب رو بچسبون تا کمتر بلاک بشی — با extension مثل "Get cookies.txt LOCALLY"
4. ذخیره کن
5. بزن "شروع استریم"، وضعیت و لاگ زنده رو زیرش می‌بینی

## نکات مهم
- اگه با خطای `403`/`429`/`Sign in to confirm you're not a bot` مواجه شدی: کوکی رو آپدیت کن، یا فیلد پروکسی رو با یک پروکسی رزیدنشیال پر کن.
- کوکی‌ها معمولاً بعد چند هفته منقضی میشن، پس هر از گاهی باید دوباره اکسپورت و جایگزین بشن.
- تنظیمات و کوکی در `/data/config.json` روی یک Volume ذخیره میشه؛ اگر می‌خوای این اطلاعات بین دیپلوی‌ها حفظ بشه، در Railway یک Volume به مسیر `/data` وصل کن (Settings سرویس → Volumes).
